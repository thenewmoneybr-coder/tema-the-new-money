# Tema roxo The New Money

Tema para o app do Claude (computador e celular) com as cores da marca The New Money: fundo preto arroxeado, destaques em roxo vibrante #9400CC e roxo escuro #3D0055, e o símbolo da marca (círculo roxo com estrela de quatro pontas) espalhado pelo fundo, flutuando devagar. Não aparece no site claude.ai nem no terminal.

## Instalar

No Claude Code, digite:

```
/plugin install the-new-money-roxo --marketplace thenewmoneybr-coder/tema-the-new-money
```

Responda `y` para adicionar o marketplace e escolha onde instalar. O tema liga sozinho quando uma sessão começa.
